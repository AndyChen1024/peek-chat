# Technical Debt Tracker — Peek Chat

> 版本: v1.0 | 2026-08-06
>
> **用途**: 追踪已知技术债务项。Agent 和人类在修改代码前应查阅此文档，
> 确认不会加剧已有债务。解决债务时应更新对应条目的状态。
>
> 遵循 Harness Engineering 的「高息贷款」隐喻：不断小额偿还，远好过累积后痛苦解决。

---

## 债务等级

| 等级 | 含义 | 行动策略 |
|------|------|---------|
| 🔴 Critical | 每次改动都在加剧，必须尽快解决 | 下个 sprint 必须处理 |
| 🟡 Medium | 显著影响开发效率，但可暂时容忍 | 计划在本 phase 内解决 |
| 🟢 Low | 代码味道，不影响功能 | 有空就修，定期批量处理 |

## 债务发现协议

当 Agent 或人类在代码中发现技术债务时：

1. 在此文档中添加新条目（分配 ID、等级、描述）
2. 在代码中标注 `// TODO(TD-XXX): ...` 引用此条目
3. 如果该债务正在被积极引入（新代码）→ 先确认是否可避免，不可避则新建条目
